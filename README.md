# Currency Converter

A simple and responsive currency converter built using **HTML, CSS, and JavaScript**. It allows users to convert currencies using exchange rates.

## Live Demo

[Currency Converter](https://currency-converter-t2sf.onrender.com/)

## Features

- Convert between different currencies.
- Country flags for currency selection.
- Simple and user-friendly interface.
- Real-time exchange rate fetching.

## Technologies Used

- HTML
- CSS
- JavaScript
- Exchange Rate API

## Run Locally

1. Clone the repository:
   https://github.com/Batuk55/currency-converter.git
2. Open the project folder.
3. Run `index.html` in your browser.
